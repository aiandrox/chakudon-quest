# 道中記の言い回し

1杯ごとの道中記に出てくる文の一覧。管理用。

- 定義は `lib/features/journal/journal_phrases.dart`
- 上から順に、当てはまる文を1つずつつないで道中記にする。候補が複数あるときは、記録ごとに1つに決まる（開くたびには変わらない）
- `{ }` の中は、その1杯の数字や名前に置き換わる
- 候補の並びを変えたり候補を足したりすると、過去の道中記の文も変わる
- 言い回しを足したり変えたりしたら `flutter test --dart-define=UPDATE_JOURNAL_CATALOG=true test/tool/journal_catalog_test.dart` でこの一覧を作り直す

## 書き出し

| いつ | 言い回し |
|---|---|
| 願を掛けた店で食べた（きっかけなし） | {日付}、願を掛けた店。 |
| 願を掛けた店で食べた（きっかけあり） | {日付}、願を掛けた店。きっかけは「{きっかけ}」。 |
| 初めての店で、食べずに撤退 | 初めて挑む道場。<br>まだ見ぬ道場へ。 |
| 初めての店 | まだ見ぬ{軒}軒目の道場へ。<br>{軒}軒目の道場の暖簾をくぐる。<br>新たな道場、{軒}軒目。 |
| 2度目以降の店 | 通うこと{度}度目。<br>{度}度目の来訪。<br>またこの暖簾をくぐる。{度}度目。<br>勝手知ったる道場、{度}度目。 |

## 時間帯・曜日・季節

| 土日 | 休日の気ままな一杯。 |
| 金曜の18時以降 | 花金の一杯。 |

| いつもの店から20km以上80km未満 | 遠く{地名}まで足をのばして。<br>はるばる{地名}へ。<br>少し遠出して{地名}へ。<br>今日は{地名}まで遠出。<br>{地名}まで、ひと足のばして。<br>見知らぬ{地名}の街で。 |

## 撤退

{理由}は撤退のメモ（10文字以内）。無いか長いときは「思わぬ壁」

| いつ | 言い回し |
|---|---|
| 前回この店で撤退した | 前回は{理由}に阻まれ、撤退した。 |
| この店で続けて2回以上撤退した | {回}度の撤退を越えて、ここまで来た。 |
| 並んでから撤退した | {分}分並んだが、 |
| 撤退した | {理由}に阻まれ、撤退。 |
| 撤退した（締め） | 次こそは。<br>この借りは、必ず返す。 |

## 着丼

{一杯}は「限定の」＋系統名＋「の一杯」（系統なしは「ラーメンの一杯」）。共有カードで修行点を外すため「、修行点 {点}」の形は崩さない

| いつ | 言い回し |
|---|---|
| 願の店・撤退のあと・60分以上並んだ | ついに着丼。{一杯}、修行点 {点}。 |
| そのほか | 着丼。{一杯}、修行点 {点}。<br>丼が置かれた。{一杯}、修行点 {点}。<br>湯気の向こうに{一杯}、修行点 {点}。<br>待望の{一杯}、修行点 {点}。 |
